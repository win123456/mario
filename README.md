# การพจญภัยของครูเรียว

เกมแพลตฟอร์ม 2 มิติสำหรับสถาบันเสริมทักษะหฤทัยจุทาราชห์ ตัวละครใส่สูท ใช้เนคไทเป็นอาวุธ ออกจากบ้านผ่านด่านภาษาไทย คณิตศาสตร์ และภาษาอังกฤษ ไปถึงอาคารสถาบันสีฟ้า

เล่นออนไลน์: https://tiny-tie-adventure.vercel.app

## เปิดเกมในเครื่อง

ใช้ Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```sh
npm run dev
```

เปิด http://127.0.0.1:5173

## วิธีเล่น

- ลูกศรซ้าย–ขวา หรือ A/D: เดิน
- Space, ลูกศรขึ้น หรือ W: กระโดด
- X: ฟาดเนคไท
- P หรือ Escape: หยุด/เล่นต่อ
- Enter: เริ่มเกมหรือไปด่านถัดไป
- มือถือ: ใช้ปุ่มบนหน้าจอ

เสียงเปิดเป็นค่าเริ่มต้น และเริ่มทำงานหลังผู้เล่นกดเริ่มเกม ปุ่มโน้ตดนตรีใช้เปิด–ปิดเสียงได้

## ไฟล์หลัก

- `dist/index.html`: หน้าเกมและข้อความภาษาไทย
- `dist/style.css`: รูปแบบ สี และหน้าจอมือถือ
- `dist/game.js`: ฟิสิกส์ การวาดฉาก ตัวละคร ศัตรู เสียง และด่านทั้ง 3
- `dist/storybook.js`: ภาพฉากนิทาน พื้นหญ้า ก้อนหิน ดอกไม้ เถาวัลย์ โคมไฟ และสไปรต์
- `dist/assets/storybook/`: ภาพหุบเขา บ้าน ครูเรียว และต้นไม้ที่ใช้จริงในเกม
- `dist/assets/emblem-mark.png`: ตราสถาบันสำหรับหน้าเกมและอาคารเส้นชัย
- `serve.cjs`: เซิร์ฟเวอร์ท้องถิ่น
- `check.cjs`: ตรวจระบบเกมด้วย Node.js

## ทดสอบ

```sh
npm test
```

ตรวจการกระโดด ลงพื้น เก็บดาว โจมตี หยุดเกม เสียหัวใจ ผ่านด่าน ชนะเกม เริ่มใหม่ และเนื้อหาทั้งสามวิชา การทดสอบนี้ใช้ Canvas จำลอง จึงยังต้องเปิดเบราว์เซอร์เพื่อตรวจภาพและเสียงจริง

## เผยแพร่บน Vercel

Import repository นี้ เลือก Framework Preset เป็น **Other** ใช้ Output Directory เป็น `dist` และไม่ต้องตั้ง Build Command โครงการมี `vercel.json` รองรับไว้แล้ว

## ที่มาของอัตลักษณ์สถาบัน

ชื่อ ตรา สี และแนวคิดการเรียนรู้อ้างอิงจาก https://haruthai-jutarach.vercel.app/ เพื่อใช้กับเกมของสถาบันนี้

ภาพเวอร์ชันนิทานปรับตามภาพอ้างอิงที่ผู้ใช้ให้มา รายละเอียดงานภาพ ที่มาของภาพที่สร้างด้วย ImageGen และคำสั่งสร้างภาพอยู่ใน [`docs/visual-direction.md`](docs/visual-direction.md)
